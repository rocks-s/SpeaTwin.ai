ENG

A full-stack service for generating a talking AI-twin. Just upload a photo of the person, enter the text, and get a ready-made video!  
Key features:  choose style, setting, and voice.  

<pre>
Tech stack:  
  
  Frontend:  
    Next.js x JS  
  Backend:  
    Node.js x Express.js  
    Services: heygen.com  

Running:
  
  Frontend:
    cd ./frontend
    setup .env.local
    npm run dev
  Backend:
    cd ./backend
    setup .env
    npm run dev
